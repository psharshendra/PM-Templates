# 🧠 Prompt Library for Project Managers

Ready-to-use AI prompts for everyday PM tasks. Copy, paste, customise and ship.

---

## 📋 Project Initiation

### Draft a Project Charter
Act as a senior project manager. Draft a project charter for [project name].
The project involves [brief description]. Key stakeholders are [list].
Timeline is [duration]. Budget is approximately [amount].
Include: objectives, scope, assumptions, constraints, risks and success criteria.

### Stakeholder Analysis
Create a stakeholder analysis for a [project type] project in a [industry] organisation.
Identify key stakeholder groups, their interests, influence level,
and recommended engagement strategy. Format as a table.

## ⚡ Agile & Scrum

### Sprint Planning
We are planning Sprint [number] for [project name].
Team velocity: [X] story points. Available capacity: [X] days.
Backlog items: [list with estimates].
Help me select items, write a sprint goal and flag dependencies or risks.

### Retrospective Facilitator
Facilitate a sprint retrospective for a team of [X] people
who completed a [X]-week sprint delivering [describe work].
Generate 4 questions each for:

What went well
What didn't go well
What can we improve
Make them specific and action-oriented.


### Daily Standup Summary
Summarise the following standup notes into a concise update
for a project manager. Extract: completed tasks, planned tasks,
blockers and any risks. Notes: [paste standup notes].

## ☁️ Azure Cloud PM

### Cloud Migration Risk Assessment
We are migrating [application name] to Azure.
Current infrastructure: [describe]. Business criticality: [High/Medium/Low].
Identify the top 10 migration risks, their likelihood,
impact and mitigation strategies. Format as a risk register table.

### Azure Governance Framework
Create an Azure governance framework for a new cloud project
in a [industry] organisation with [X] users.
Cover: naming conventions, RBAC roles, resource tagging strategy,
cost management controls, security baseline and compliance requirements.

### Azure Cost Optimisation
Review the following Azure cost report: [paste data or describe spend].
Identify the top 5 cost optimisation opportunities.
For each provide: current spend, recommended action,
estimated saving and implementation effort.

## 📊 Reporting

### Weekly Status Report
Draft a one-page weekly status report for [project name].
Completed this week: [list]. Planned next week: [list].
Risks & issues: [list]. Budget status: [on track/over/under].
RAG status: [Red/Amber/Green] — reason: [explain].
Audience: C-suite. Tone: concise, factual, action-oriented.

### Executive Summary
Summarise the following project update into a 5-bullet
executive summary for a board-level audience.
Focus on: business impact, timeline, budget,
key risks and decisions required.
Update: [paste your update]. Maximum 150 words.

## 🚨 Risk & Issues

### Risk Register Population
Generate a risk register for a [project type] project
in a [industry] organisation. Include 10 risks covering:
technical, resource, timeline, stakeholder and compliance categories.
For each: Risk ID, Description, Category, Probability (H/M/L),
Impact (H/M/L), Risk Score, Owner, Mitigation Strategy.

### Escalation Email
Draft a professional escalation email to [recipient role]
regarding [issue description] on [project name].
The issue has been ongoing since [date].
Impact if unresolved: [describe]. Recommended resolution: [your suggestion].
Tone: firm but collaborative.

## 💬 Stakeholder Communications

### Project Delay Notification
Write a stakeholder communication announcing a [X week] delay
to [project name]. Cause: [reason]. New go-live date: [date].
Recovery steps: [list]. Audience: [stakeholder group].
Tone: transparent, accountable, solution-focused.

### Difficult Stakeholder Conversation Prep
Help me prepare for a difficult conversation with [stakeholder role]
who is [describe concern]. My position: [your stance].
Their concern: [their concern].
Suggest: how to open, key talking points,
likely objections and how to handle them.
